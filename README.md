# 🐾 PawCare – Pet Care Website

PawCare is a responsive pet-care startup website designed to provide simple, reliable, and convenient pet-care services for pet owners.

## 🌐 Live Website

**Live Demo:** https://pawcare-ebon.vercel.app/

## 📂 GitHub Repository

**Repository:** https://github.com/duashah110/pawcare

## ✨ Features

* 🏠 Home section with an attractive hero area
* 🐾 About PawCare section
* 🛁 Professional Grooming service
* 🐕 Daily Walks service
* 🏠 Pet Sitting service
* 🩺 Wellness Care service
* 📧 Contact information
* 📞 Phone and email details
* 📍 Location information
* 📱 Responsive design for desktop, tablet, and mobile
* 🌙 Dark Mode / Light Mode toggle
* ✨ Hover effects and smooth scrolling
* 🖼️ Dog and cat images

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* CSS Flexbox
* CSS Grid
* Responsive Media Queries
* Vercel for deployment
* GitHub for version control

## 📖 Project Sections

### Home

Introduces PawCare and provides a short overview of the services.

### About

Explains the purpose of PawCare and how it helps pet owners.

### Services

Displays the main pet-care services offered by PawCare.

### Contact

Provides PawCare's contact information, including email, phone number, and location.

## 📱 Responsive Design

The website is designed to work across different screen sizes, including:

* Desktop
* Tablet
* Mobile

CSS media queries are used to adjust the layout for smaller screens.

## 🌙 Dark Mode

PawCare includes a Dark Mode toggle implemented using JavaScript. Users can switch between Light Mode and Dark Mode by clicking the button in the navigation bar.

## 🚀 Deployment

The website is deployed using Vercel.
